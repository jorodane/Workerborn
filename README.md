# WorkerBorn · 솔바람 마을

직접 일하며 생활 스킬과 경력을 쌓고, 환생을 거쳐 발전한 마을로 돌아오는 Unity 프로토타입입니다. 마비노기의 클릭 이동, NPC 대화 키워드, 생활 스킬, 격자 소지품과 이동 가능한 정보 창을 UX 참고로 삼았습니다.

## 실행

1. **Unity 6000.3.5f2**로 프로젝트를 엽니다. URP 17.3.0, Input System 1.17.0을 사용합니다.
2. **Workerborn → Village Prototype → Play Village**를 선택합니다.
3. 또는 `Assets/Workerborn/Scenes/VillagePrototype.unity`를 열고 Play를 누릅니다.

마을과 UI는 **Play 모드에서 생성**됩니다. 기본 빌드의 첫 씬도 `VillagePrototype`입니다. 기존 `HarvestPrototype`은 수확만 시험하는 별도 씬으로 보존합니다.

## 첫 번째 삶

1. 서쪽 농장주 **미라**를 클릭해 다가간 뒤 **아르바이트** 키워드를 선택합니다. `[Q]`의 **미라 찾아가기** 버튼으로도 안내받을 수 있습니다.
2. 작물을 클릭하면 이동해 머리 위 스킬 풍선과 함께 작업합니다. 기본 **작물당 3회, 회당 2.4초, 감자 2개**입니다. 가끔 럭키 보너스가 발생합니다.
3. 바닥에 떨어진 감자를 클릭해 줍습니다. **수확만으로 가방에 들어가지는 않습니다.**
4. **18:00 전**에 미라에게 감자 6개를 납품해 45G·경험치·경력을 받습니다. 보고하지 못하면 실패하며 하루에 한 번 접수합니다.
5. **마을의 새 일꾼** 퀘스트 보상도 받습니다. `[K]`에서 AP로 수확 스킬을 승급합니다.
6. 북쪽 잡화점의 **노아**에게 감자를 팔거나 빵·괭이·가방을 삽니다. 빵은 에너지 회복, 괭이는 작업 효율 상승, 가방은 공간 확장 효과가 있습니다.
7. 동쪽 여관의 **레나**에게 잠자리를 부탁합니다. 무료 잠자리는 에너지 70, 10G 객실은 100으로 다음 날 06:00에 시작합니다. 밭은 매일 준비되며 소지품과 바닥 물품은 유지됩니다.
8. 퀘스트 보상을 받고 **레벨 3**이 되면 북쪽 **기억의 샘**에서 환생합니다. 확인 화면에서 잃는 재산과 유지되는 성장을 검토한 뒤 실행합니다.

시간은 실제 1초당 게임 3분입니다. **대화 중에는 멈추고**, 일반 정보 창을 여는 동안에는 흐릅니다. 자정까지 깨어 있거나 에너지가 0이 되면 쓰러져 다음 날 에너지 45로 시작합니다.

## 다음 삶에 남기는 것

| 초기화 | 유지 |
| --- | --- |
| 현재 레벨·경험치, 골드, 소지품, 도구, 가방, 진행 중인 의뢰 | 생활 스킬, 남은 AP, 누적 레벨, 경력, 완료한 이야기, 농장 기부와 확장 |

미라의 **농장 확장**에 **100G와 감자 20개**를 기부하면 공사가 예약됩니다. 다음 환생 후 밭이 **12개에서 24개**로 늘고, 같은 경력에서도 더 큰 의뢰를 받습니다. 여러 번에 나누어 기부할 수 있으며 기부 내역은 환생 후 유지됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 이동 / 수확 / 바닥 물품 줍기 / NPC에 다가가 대화 |
| 우클릭 | 이동·작업 취소. 미완료 작업은 횟수와 에너지를 보존 |
| F1 / F2 | 가장 가까운 작물 수확 / 가방의 빵 사용 |
| I / Q / K / C / M | 소지품 / 퀘스트 / 스킬 / 캐릭터 / 지도 |
| Esc | 대화·정보 창 닫기, 작업 취소 |
| 휠 / 가운데 버튼 드래그 | 확대·축소 / 시점 회전 |
| 창 제목 표시줄 드래그 | 정보 창 이동 |
| 소지품 물건 드래그 | 여러 칸을 차지하는 물건 배치, 같은 물건 겹치기 |
| 소지품의 빵 우클릭 | 사용. 선택 후 사용·반으로 나누기 버튼도 지원 |
| 지도 클릭 | 해당 위치로 이동 |

가방이 가득 차면 감자는 바닥에 남습니다. 중첩·분할 시 수량을 보존하며, 놓을 수 없는 칸이나 창 밖으로 옮기면 원래 자리를 유지합니다. R 초기화는 기존 수확 전용 씬에서만 작동합니다.

## 저장과 검증

`Application.persistentDataPath/workerborn-village-v1.json`에 15초 주기와 주요 행동 후 자동 저장합니다. 수동 저장도 지원합니다. 인벤토리 칸·수량, 캐릭터 위치, 시간, 성장, 의뢰, 퀘스트, 세계 변화, 남은 수확 횟수와 바닥의 감자를 함께 기록합니다. 이전 저장은 `.bak`으로 보관하며 읽기에 실패하면 백업 복구를 시도합니다.

```bash
dotnet run --project Tests/HarvestLogic/HarvestLogic.csproj -- --noheader --nocolor --workers=0
python Tests/validate_harvest_assets.py
```

수확·인벤토리·일일 마감·보상 중복·거래·성장·환생·저장 검증의 NUnit 테스트를 같은 소스로 .NET과 Unity EditMode에서 실행합니다. Unity PlayMode에는 이동·대화·수확·납품·환생·저장 재로드 테스트가 있습니다. 테스트 저장 폴더는 플레이어 데이터와 분리됩니다.

이 작업 환경에는 Unity 에디터가 없어 실제 Unity PlayMode 실행과 화면 검증은 수행하지 못했습니다. Unity에서의 컴파일과 PlayMode 테스트로 최종 확인이 필요합니다.

현재는 감자 알바 1종, NPC 3명, 이야기 퀘스트 2개, 생활 스킬 1종, 농장 확장 1단계를 연결한 프로토타입입니다. 자유 건설·이사·도시 재개발·다양한 제작 직종은 이후 범위입니다. 원본 에셋과 `SampleScene`은 보존합니다.
